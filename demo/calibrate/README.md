# 最小校准

三题分别测试精确文本处理、JSON 类型边界和 Unicode 游程编码，均由独立输入输出机器判分，不让工人改评分器。候选按当前 CLI 版本的可用性排序，每个候选选择一个默认档位；模型清单、题数和费用提示在确认前展示。

只有明确的模型不支持错误会自动切换到同一工人的下一个候选，最多换 3 个（含首选共 4 次），每次开新轮次；OpenCode 可切换已登记的提供商。其他原因失败不自动重试。被拒绝模型停止后续题目，切换后的候选继续答题；本批次已尝试的同一模型、同一题不重复执行。所有拒绝尝试保留在表现记录和报告里。

通过率来自三题的整题通过数，时间为实际墙钟秒。回执没有费用时写“未知”，不根据 token 猜金额；Codex 标注订阅额度。评分结果和每轮回执路径保留，以便复查。校准只能代表这三个小题，路由建议不代表复杂项目能力。

通过率的分母为实际尝试题数，被拒绝后停止的模型可能只测了 1 题。`ok` 只代表工人正常完成，答案仍需评分。校准完成出报告即返回 0，失败组合在 `work_dir/路由建议.md` 逐项列明。`aw doctor --live` 复用第一题并写 `自检报告.md`，退出码按各工人最终验收结果决定。
